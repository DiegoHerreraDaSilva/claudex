          Modelos dos agentes

          

            Jev escolhe o agente para cada pedido e colaborador. Você escolhe o modelo de cada um.
          


          

          

            
          

          

            
            
          


          

          

            
          

          

            
            
          


          

          

            
          

          

            
            
          

          

            Mais esforço pode aumentar o tempo e o uso de tokens. O suporte depende do modelo. Vale
            também para colaboradores; mudar o esforço mantém a sessão.
          


          
            

            

            

            

            
          

          

            Use um modelo disponível na sua conta. Ao mudar o modelo, ele recebe o histórico
            compartilhado do projeto.
          


          

            Para uma versão específica, use o identificador completo: Sonnet 5.5 é
            claude-sonnet-5-5 e Opus 5.5 é claude-opus-5-5. Os nomes
            sonnet e opus usam os aliases do provedor.
